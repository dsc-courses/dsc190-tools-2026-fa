# Resources

Each directory contains some supplemental information. Here's what is in each:

- `./00-initial_setup`: instructions for getting a terminal and Unix-like
  environment set up on your machine.
- `./01-unix_on_mac`: getting a Unix-like environment on macOS.
- `./01-unix_on_windows`: getting a Unix-like environment on Windows (via WSL).
- `./02-picking_an_ai`: advice on choosing an AI coding agent subscription for
  the course.
- `./03-docker_container_sandboxes`: running coding agents inside Docker
  containers as a sandbox.
